# EST002: An event source class must not be an abstract class

| | |
|---|---|
| Rule ID | EST002 |
| Category | General |
| Severity | Error |
| Reported by | `EventSourceClassSignatureAnalyzer` |

## Cause

A class annotated with `GeneratedEventSourceAttribute` is declared `abstract`. The diagnostic is
reported on the declaration that actually carries the `abstract` modifier, which may be a different
partial part from the one carrying the attribute.

## Rule description

`EventSource` is designed around a concrete type. The event manifest is derived from the members of
the type that is instantiated and registered with ETW or EventPipe, and the generated event writing
methods are instance members that call `protected` members of `EventSource`. An abstract class can
never be instantiated, so nothing it declares would ever write an event.

Generating code for an abstract class would therefore produce a manifest and a set of methods that
can never run, which is almost always a sign that the attribute was applied to the wrong type in a
class hierarchy.

## How to fix violations

Either remove the `abstract` modifier, or move `GeneratedEventSourceAttribute` to the concrete class
that is actually instantiated.

Sharing members across several event sources is still possible: declare the abstract base class
*without* `GeneratedEventSourceAttribute`, and apply the attribute only to the leaf concrete classes.
Each leaf then gets its own generated methods and its own manifest, which is what `EventSource`
expects.

## When to suppress

Do not suppress this diagnostic. There is no scenario in which an abstract event source can emit
events, so suppressing it only replaces a clear error with a silent lack of generated code.

## Example

### Violation

```csharp
using System.Diagnostics.Tracing;
using Aetos.EventSourceToolkit;

[GeneratedEventSource]
[EventSource(Name = "Contoso-Sample")]
public abstract partial class SampleEventSourceBase : EventSource // EST002
{
    [Event(1)]
    public partial void Started(string name);
}
```

### Fix

```csharp
using System.Diagnostics.Tracing;
using Aetos.EventSourceToolkit;

public abstract class SampleEventSourceBase : EventSource
{
    // Members shared by every derived event source, written by hand.
}

[GeneratedEventSource]
[EventSource(Name = "Contoso-Sample")]
public sealed partial class SampleEventSource : SampleEventSourceBase
{
    [Event(1)]
    public partial void Started(string name);
}
```
