# EST001: An event source class must be a partial class

| | |
|---|---|
| Rule ID | EST001 |
| Category | General |
| Severity | Error |
| Reported by | `EventSourceClassSignatureAnalyzer` |

## Cause

A class annotated with `GeneratedEventSourceAttribute`, or one of the types that contain it, is not
declared `partial`.

## Rule description

The source generator writes the bodies of the event writing methods into a separate file, as an
additional part of your event source class. A type can be split across several files only when every
declaration involved is declared `partial`, and that requirement applies to the whole containing
chain: if the event source class is nested, each enclosing type must be `partial` as well, otherwise
the generator has no way to reopen it.

The C# compiler already reports CS0260 when a type has more than one declaration and one of them is
missing the `partial` modifier. EST001 exists because it fires earlier and points at the declaration
that actually needs the modifier, which is more useful than an error about a file you did not write.

## How to fix violations

Add the `partial` modifier to the declaration named in the message. The message names the specific
type that is missing it, which is not necessarily the event source class itself.

## When to suppress

Do not suppress this diagnostic. Suppressing it does not make the generator emit anything; the
declared partial methods stay unimplemented and the compilation fails with a less helpful error.

## Example

### Violation

```csharp
using System.Diagnostics.Tracing;
using Aetos.EventSourceToolkit;

public static class Outer // EST001: 'Outer' is not declared partial
{
    [GeneratedEventSource]
    [EventSource(Name = "Contoso-Sample")]
    public sealed partial class SampleEventSource : EventSource
    {
        [Event(1)]
        public partial void Started(string name);
    }
}
```

### Fix

```csharp
using System.Diagnostics.Tracing;
using Aetos.EventSourceToolkit;

public static partial class Outer
{
    [GeneratedEventSource]
    [EventSource(Name = "Contoso-Sample")]
    public sealed partial class SampleEventSource : EventSource
    {
        [Event(1)]
        public partial void Started(string name);
    }
}
```
