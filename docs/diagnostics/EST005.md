# EST005: An event method parameter must have a supported type

| | |
|---|---|
| Rule ID | EST005 |
| Category | General |
| Severity | Error |
| Reported by | `EventSourceMethodSignatureAnalyzer` |

## Cause

A parameter of a partial event method has a type that `EventSource` cannot serialise into an event
payload.

## Rule description

`EventSource` writes event payloads as a flat sequence of fixed-layout fields. The generated method
body has to describe each parameter to `WriteEventCore` as a pointer and a byte count, which is only
possible for types with a known blittable representation, plus the two variable-length cases that
`EventSource` handles specially.

The supported parameter types are:

- `bool`, `char`, `byte`, `sbyte`, `short`, `ushort`, `int`, `uint`, `long`, `ulong`, `float`, `double`,
  `decimal`
- `nint` (`System.IntPtr`)
- `System.DateTime`, `System.Guid`
- `string`
- `byte[]`
- any `enum` type

Anything else — including `object`, tuples, collections other than `byte[]`, and your own classes and
structs — has no defined payload layout and is rejected.

This diagnostic is reported by the analyzer, not by the source generator. When a parameter has an
unsupported type, the source generator silently skips code generation for that method instead of
reporting a diagnostic of its own; it relies on the analyzer to have already reported this diagnostic.

One parameter is exempt from the payload rules: a `System.Guid` parameter in the first position named
`relatedActivityId` (compared case-insensitively) is treated as the ETW related activity ID rather than
as a payload field, and is passed to `WriteEventWithRelatedActivityIdCore` instead.

## How to fix violations

Change the parameter to a supported type, and convert at the call site rather than inside the event
method. Converting inside the method would run even when nobody is listening to the event source, which
defeats the purpose of the `IsEnabled` check that guards event writing.

Common conversions:

| Instead of | Pass |
|---|---|
| An entity or DTO | The individual fields you actually want in the payload |
| `TimeSpan` | `long` ticks, or `double` milliseconds |
| A collection | A pre-formatted `string`, or one event per element |
| `Exception` | `exception.ToString()`, or the message and type name separately |

## When to suppress

Do not suppress this diagnostic. The parameter cannot be written to the payload, so the generated
method would either fail to compile or silently drop the value.

## Example

### Violation

```csharp
using System;
using System.Diagnostics.Tracing;
using Aetos.EventSourceToolkit;

[GeneratedEventSource]
[EventSource(Name = "Contoso-Sample")]
public sealed partial class SampleEventSource : EventSource
{
    [Event(1)]
    public partial void RequestCompleted(string path, TimeSpan elapsed); // EST005 on 'elapsed'
}
```

### Fix

```csharp
using System;
using System.Diagnostics.Tracing;
using Aetos.EventSourceToolkit;

[GeneratedEventSource]
[EventSource(Name = "Contoso-Sample")]
public sealed partial class SampleEventSource : EventSource
{
    [Event(1)]
    public partial void RequestCompleted(string path, double elapsedMilliseconds);
}
```

```csharp
eventSource.RequestCompleted(path, elapsed.TotalMilliseconds);
```
