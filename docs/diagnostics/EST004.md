# EST004: An event source class must not be a file-local class

| | |
|---|---|
| Rule ID | EST004 |
| Category | General |
| Severity | Error |
| Reported by | `EventSourceClassSignatureAnalyzer` |

## Cause

A class annotated with `GeneratedEventSourceAttribute`, or one of the types that contain it, is declared
with the `file` modifier.

## Rule description

A file-local type has a distinct identity in every file that declares it. The compiler mangles its
metadata name with a per-file component, so a `partial` part contributed from another file does not
complete the type you declared — it declares an unrelated type that happens to share a source-level
name.

That makes a file-local type impossible for the generator to augment, no matter how many `partial`
modifiers are present. What makes it worth a dedicated diagnostic is that the failure is silent: unlike
a missing `partial` modifier, which the compiler reports as CS0260, nothing in the compiler output
points at the `file` modifier as the cause. You would simply see unimplemented partial methods.

Because the `file` modifier cannot be applied to a nested type, the declaration named in the message is
always a top-level one: either the event source class itself or the outermost type containing it.

## How to fix violations

Remove the `file` modifier from the declaration named in the message.

If the type must stay invisible outside its file, `internal` is the closest alternative that the
generator can work with. It does not give the same per-file isolation, so pick a name that will not
collide within the assembly.

## When to suppress

Do not suppress this diagnostic. Suppressing it does not enable generation; the partial methods stay
unimplemented and the compilation fails without naming the real cause, which is exactly the situation
this diagnostic exists to prevent.

## Example

### Violation

```csharp
using System.Diagnostics.Tracing;
using Aetos.EventSourceToolkit;

[GeneratedEventSource]
[EventSource(Name = "Contoso-Sample")]
file sealed partial class SampleEventSource : EventSource // EST004
{
    [Event(1)]
    public partial void Started(string name);
}
```

### Fix

```csharp
using System.Diagnostics.Tracing;
using Aetos.EventSourceToolkit;

[GeneratedEventSource]
[EventSource(Name = "Contoso-Sample")]
internal sealed partial class SampleEventSource : EventSource
{
    [Event(1)]
    public partial void Started(string name);
}
```
