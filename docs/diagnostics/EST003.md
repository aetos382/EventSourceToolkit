# EST003: An event source class must derive from System.Diagnostics.Tracing.EventSource

| | |
|---|---|
| Rule ID | EST003 |
| Category | General |
| Severity | Error |
| Reported by | `EventSourceClassSignatureAnalyzer` |

## Cause

A class annotated with `GeneratedEventSourceAttribute` does not derive, directly or indirectly, from
`System.Diagnostics.Tracing.EventSource`.

## Rule description

The generated method bodies call `WriteEvent` and `WriteEventCore`, which are `protected` members of
`EventSource`. Those calls only compile inside a type that inherits them, so the generator has nothing
to generate for a class outside the `EventSource` hierarchy.

Deriving indirectly is fine — an intermediate base class that itself derives from `EventSource` still
provides the members the generated code needs. The base class list may also appear on any partial part
of the class, so a declaration without a base list is not a violation as long as another part supplies
one.

## How to fix violations

Add `System.Diagnostics.Tracing.EventSource` (or a class derived from it) to the base class list of the
event source class.

If the class is not meant to be an event source at all, remove `GeneratedEventSourceAttribute` instead.

## When to suppress

Do not suppress this diagnostic. Suppressing it moves the failure into the generated file, where the
resulting `CS0103`/`CS0122` errors point at code you cannot edit.

## Example

### Violation

```csharp
using System.Diagnostics.Tracing;
using Aetos.EventSourceToolkit;

[GeneratedEventSource]
[EventSource(Name = "Contoso-Sample")]
public sealed partial class SampleEventSource // EST003
{
    [Event(1)]
    public partial void Started(string name);
}
```

### Fix

```csharp
using System.Diagnostics.Tracing;
using Aetos.EventSourceToolkit;

[GeneratedEventSource]
[EventSource(Name = "Contoso-Sample")]
public sealed partial class SampleEventSource : EventSource
{
    [Event(1)]
    public partial void Started(string name);
}
```
