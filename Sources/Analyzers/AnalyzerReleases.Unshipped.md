### New Rules

Rule ID | Category | Severity | Notes
--------|----------|----------|--------------------
EST001  | General  | Error    | An event source class must be a partial class
EST002  | General  | Error    | An event source class must not be an abstract class
EST003  | General  | Error    | An event source class must derive from System.Diagnostics.Tracing.EventSource
EST004  | General  | Error    | An event source class must not be a file-local class
